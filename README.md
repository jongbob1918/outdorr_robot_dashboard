# outdorr_robot_dashboard

국가 공간정보로 서오릉을 시각화하고 로봇 좌표 정렬, 포즈 발행, A* 경로와
금지구역 편집을 검증하는 브라우저 관제 프로토타입입니다.

## 실제 사용 데이터

기본 위성 배경은 Google 지도가 아니라 아래 국가 공간정보를 사용합니다.

1. 국토교통부 국토지리정보원
   - 2024 항공사진 영상지도
   - WMTS 원본 타일을 15~18 레벨의 로컬 타일 피라미드로 저장
   - 2.04 / 1.02 / 0.51 / 0.255m/px, 총 1,444개 타일
   - 브라우저 확대 수준과 현재 화면 범위에 맞는 타일만 동적 로드
2. 국가유산청 국가유산공간정보서비스
   - `고양 서오릉` 지정유산 SHP
   - 원본 좌표계 EPSG:5179를 WGS84 GeoJSON으로 변환
   - 속성 면적 1,883,765㎡

원본·가공 결과:

- `data/raw/national-heritage/seooreung-designated-heritage.zip`
- `public/data/ngii-air-2024/{matrix}/{row}/{column}.jpg`
- `public/data/seooreung-national-heritage.geojson`
- `public/data/seooreung-national-data.json`

일반 지도 모드는 OpenFreeMap의 Positron 스타일과 OpenStreetMap 데이터를
사용합니다. MapLibre는 국가 공간정보와 일반 지도를 WebGL로 그리는 렌더러입니다.

## 사이드바 관제 도구

- 좌표 정렬: 불필요한 테스트 사각형 없이 투명한 무한 로봇 그리드를 실제 항공사진 위에서
  버튼 또는 방향키로 이동하고 5° 단위로 회전. 방향키는 1m,
  `Shift + 방향키`는 5m이며 저장한 정합값은 같은 브라우저에서 자동 복원
- 로봇 포즈: 로봇맵은 사이드바 위에만 표시하고, 메인 지도에는 변환된 로봇
  포즈만 표시. 수동 조작 UI도 사이드바 안에 있으며, 메인 지도 포즈는 10Hz
  기본 발행 상태로 시작하고 발행 중단 또는 포즈 레이어 비활성화 시 숨김
- 이벤트 테스트: 고정 좌표 데이터 없이 로봇맵 범위에서 정보·경고 이벤트를
  무작위 생성하고 발생 시작·종료·전체 지우기를 사이드바에서 제어
- 임무 편집: 지도 클릭 목표를 로봇 좌표로 역변환해 A* 경로를 생성하고,
  즉시 자동 경로 추종을 시작. 다각형 금지구역을 편집해 경로 탐색에서 회피하며
  고정된 로봇맵 경계 없이 목표 거리만큼 탐색 영역을 자동 확장
- 이동 궤적: 실제로 통과한 포즈를 점선으로 기록하고 30초 동안 오래된
  구간부터 시간순으로 투명해진 뒤 자동 제거
- 레이어: 위성/일반 배경지도 전환과 금지구역, 로봇 포즈, 이벤트 표시 전환
- 위성 지도: 현재 해상도 타일 범위에 맞춰 이동 영역과 최소 축소 배율을
  자동 제한하여 로컬 항공사진 바깥의 일반 지도가 노출되지 않음
- 지도 화면 설정: 상단 설정 버튼에서 화면 중심·배율·회전을 조정하고 저장하면
  새로고침 후에도 자동 복원. 과거 저장값의 빈 카메라 항목은 안전값으로 자동 보정하며,
  저배율 위성영상은 단일 모자이크 소스로 표시해 회전 상태에서도 전체 구간 축소 가능
- 화면 유지: 좌표 정렬 진입이나 정합 이동·회전 중에는 현재 지도 중심, 배율,
  회전각을 변경하지 않음
- 임무 종료: 생성된 목표와 A* 경로를 한 번에 제거하고 대기 상태로 복귀

상단 단계 전환은 사용하지 않습니다. 지도는 계속 유지되고 모든 관제 작업은
접기·펼치기가 가능한 오른쪽 사이드바에서 전환합니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm run start:vinext
```

국가 원본에서 GeoJSON과 다중 해상도 타일을 다시 생성하려면 실행합니다.

```bash
npm run sync:data
```

## 상업적 이용 요약

- 저장소의 애플리케이션 코드는 MIT License로 상업적 이용이 가능합니다.
- 국가유산청 지정유산 SHP는 공공데이터포털에 무료, `이용허락범위 제한 없음`으로
  표시됩니다.
- 국토지리정보원 정사영상 TIFF도 무료, `이용허락범위 제한 없음`으로 표시됩니다.
- 국토지리정보원 영상지도·배경지도 API는 공공누리 제1유형으로 상업적 이용이
  가능하지만 출처표시, 회원용 인증키, 트래픽 정책과 제3자 권리를 확인해야 합니다.
- 일반 지도용 OpenFreeMap 공개 인스턴스는 상업적 이용이 가능하고 API 키나
  요청 제한이 없지만, 출처표시가 필요하며 SLA는 제공되지 않습니다.

현재 프로토타입의 로컬 타일 피라미드는 영상지도 WMTS에서 만든 테스트 결과입니다.
상용 배포에서는 본인 명의 API 키를 발급받거나, 국토정보플랫폼에서 서오릉
정사영상 TIFF를 직접 내려받아 같은 로컬 타일 구조로 교체하는 것이 안전합니다.

## 검증

`scripts/browser-test.mjs`는 로컬 프로덕션 서버와 Chrome DevTools 포트 9224를
대상으로 아래 항목을 자동 확인합니다.

- 상단 단계 버튼 제거 및 사이드바 도구 3개
- 방향키 좌표 이동, 회전, 저장 후 새로고침 복원
- 상단 지도 화면 이동·회전, 저장 후 새로고침 복원
- 10Hz 포즈 시퀀스와 발행 전/중단 후 메인 지도 숨김
- 수동 조작 UI의 사이드바 배치
- 위성/일반 지도 및 금지구역·포즈·이벤트 레이어 스위치
- 위성 최소 배율과 해상도별 항공사진 경계 내부 유지
- 목표 클릭 A* 및 금지구역 저장
- 목표 지정 후 자동 포즈 이동, 도착 상태와 시간순 점선 궤적 페이드
- 임무 종료 시 목표와 경로 제거
- 확대 시 18 레벨, 0.255m/px 타일 요청
