# outdorr_robot_dashboard

서오릉 야외 로봇 관제를 위한 브라우저 UI 프로토타입입니다.

현재 배경지도는 라이선스가 있는 외부 지도 타일이 아니라, UI 동작을 확인하기 위한
로컬 벡터 데모입니다. 실제 서비스에서는 국토지리정보원 정사영상 GeoTIFF를 내려받아
타일로 변환한 뒤 MapLibre 또는 OpenLayers의 raster source로 연결하는 구성을 권장합니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm run preview
```

## 구현된 데모 기능

- 로봇 3대 상태 및 텔레메트리 표시
- 로봇 선택과 지도 마커 연동
- 경로, 안전구역, 장애물, 지형 레이어 토글
- 지도 확대/축소
- 임무 일시정지/재개
- GeoTIFF 연동 절차 안내
- 데스크톱/모바일 반응형 레이아웃

## 데이터 링크 및 이용 조건

- [국토정보플랫폼 통합검색](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)
- [국토지리정보원 정사영상(TIFF)](https://www.data.go.kr/data/15059919/fileData.do)
- [국토지리정보원 수치지도(DXF)](https://www.data.go.kr/data/15015482/fileData.do)
- [국토지리정보원 DEM](https://www.data.go.kr/data/15059920/fileData.do)
- [국토지리정보원 영상지도·배경지도 API](https://www.data.go.kr/data/15059358/openapi.do)

2026년 7월 확인 기준:

- 정사영상 TIFF: 공공데이터포털에 `이용허락범위 제한 없음`, 무료로 표시
- 수치지도: 공공누리 제1유형(출처표시), 무료로 표시
- 영상지도·배경지도 API: 공공누리 제1유형이지만 제3자 권리 및 API 신청·트래픽 정책 확인 필요

따라서 공개된 일반 정사영상 및 공공누리 제1유형 수치지도는 상업적 이용이 가능합니다.
단, 실제 다운로드한 개별 데이터의 이용허락 표시가 우선하며, 출처표시와 공간정보
보안등급(특히 고해상도·좌표 포함 자료)을 반드시 확인해야 합니다.

권장 출처표시 예시:

> 본 서비스는 국토교통부 국토지리정보원의 정사영상(자료연도, 도엽명)을 이용하였습니다.
